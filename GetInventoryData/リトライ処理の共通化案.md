リトライ処理の共通化案

13_NextEngineAPI.gs（NE API用）と 19_DistributeCaller.gs（Webhook用）の両方が、同じ「エクスポネンシャルバックオフ + 特定エラーは即時失敗」というパターンをそれぞれ独自実装しています。共通化する場合、以下のような汎用ラッパー関数を新設し、両者からはそれを呼び出す形にする案です。

新規ファイル例：09_RetryHelper.リトライ共通化.gs
関数シグネチャ案：executeWithRetry(operationFn, config, isNonRetryableFn)
operationFn：実際にリトライしたい処理（引数なしの関数、呼び出し元でクロージャにして渡す）
config：{ maxRetries, retryableLogPrefix } のようなオブジェクト（RETRY_CONFIG や DISTRIBUTE_CALLER_RETRY_CONFIG を統合）
isNonRetryableFn：エラーメッセージを見て即時失敗すべきか判定する関数（NE APIは「認証/権限/token」、Webhook側は今のところ判定なし、と呼び出し元ごとに異なるため引数化）
呼び出し側（例：getBatchStockDataWithRetry）は operationFn に () => getBatchStockData(...) を渡すだけの薄いラッパーになります

Step 1: 新規ファイル 09_RetryHelper.リトライ共通化.gs

両者の挙動（成功ログ・失敗ログ・エクスポネンシャルバックオフ・即時失敗判定・最終失敗時のコールバック）を完全に維持できるよう、コールバックで差異を吸収する設計にしています。


```
/**
 * @file 09_RetryHelper.リトライ共通化.gs
 * @description エクスポネンシャルバックオフによる汎用リトライ処理を提供する共通モジュール。
 * 13_NextEngineAPI.gs（在庫マスタAPI呼び出し）と 19_DistributeCaller.gs
 * （DistributeInventory Webhook呼び出し）の両方で使用されていた、
 * ほぼ同一のリトライロジックを1箇所に集約したもの。
 *
 * ### 依存関係
 * - 参照元: 13_NextEngineAPI.API通信.gs, 19_DistributeCaller.配布呼び出し.gs
 * - 参照先: 12_Logger.ログ管理.gs (logWithLevel, logError)
 *
 * @version 1.0
 * @see executeWithRetry - 汎用リトライ実行関数
 */

/**
 * エクスポネンシャルバックオフによる汎用リトライ実行
 *
 * 【処理フロー】
 * 1. operationFn() を実行する
 * 2. 失敗した場合、isNonRetryableError(error) が true を返せば即座にスロー
 * 3. それ以外は 1秒→2秒→4秒 のエクスポネンシャルバックオフで待機し再試行
 * 4. maxRetries 回すべて失敗したら、buildFailureMessage（省略時は既定文言）で
 *    エラーメッセージを組み立ててスローする
 *
 * @param {Function} operationFn - リトライ対象の処理（引数なし）
 * @param {Object} options
 * @param {number} options.maxRetries - 最大リトライ回数
 * @param {boolean} options.enableRetry - falseの場合はリトライせず1回のみ実行
 * @param {string} options.context - ログ出力用のラベル（例: '在庫マスタAPI'）
 * @param {function(Error): boolean} [options.isNonRetryableError] - trueならリトライせず即座にスロー
 * @param {function(number): void} [options.onRetryAttempt] - 2回目以降の試行開始時に呼ばれる（attempt番号を渡す）
 * @param {function(Error): void} [options.onFinalFailure] - 全リトライ失敗確定時に呼ばれる（詳細ログ記録用）
 * @param {function(number, Error): string} [options.buildFailureMessage] - 最終エラーメッセージを組み立てる関数
 * @return {*} operationFnの戻り値
 * @throws {Error} isNonRetryableErrorがtrueを返した場合、または全リトライが失敗した場合
 */
function executeWithRetry(operationFn, options) {
    const {
        maxRetries,
        enableRetry,
        context,
        isNonRetryableError,
        onRetryAttempt,
        onFinalFailure,
        buildFailureMessage
    } = options;

    if (!enableRetry) {
        return operationFn();
    }

    let lastError = null;

    for (let attempt = 1; attempt <= maxRetries; attempt++) {
        try {
            if (attempt > 1) {
                if (onRetryAttempt) onRetryAttempt(attempt);
                logWithLevel(LOG_LEVEL.SUMMARY, `  [${context}] リトライ ${attempt}/${maxRetries}回目...`);
            }

            const result = operationFn();

            if (attempt > 1) {
                logWithLevel(LOG_LEVEL.SUMMARY, `  ✓ [${context}] リトライ成功（${attempt}回目の試行で成功）`);
            }

            return result;

        } catch (error) {
            lastError = error;

            if (isNonRetryableError && isNonRetryableError(error)) {
                logError(`  [${context}] 即座に失敗: リトライ不可能なエラー - ${error.message}`);
                throw error; // リトライせずに即座にスロー（onFinalFailureは呼ばない）
            }

            logError(`  ✗ [${context}] エラー（試行 ${attempt}/${maxRetries}）: ${error.message}`);

            if (attempt < maxRetries) {
                // エクスポネンシャルバックオフ: attempt=1失敗後→1秒, 2失敗後→2秒, 3失敗後→4秒
                const waitSeconds = Math.pow(2, attempt - 1);
                logWithLevel(LOG_LEVEL.SUMMARY, `  → ${waitSeconds}秒後にリトライします...`);
                Utilities.sleep(waitSeconds * 1000);
            }
        }
    }

    const errorMessage = buildFailureMessage
        ? buildFailureMessage(maxRetries, lastError)
        : `[${context}] 処理失敗（${maxRetries}回試行）: ${lastError.message}`;

    logError(`  ✗✗✗ ${errorMessage}`);

    if (onFinalFailure) onFinalFailure(lastError);

    throw new Error(errorMessage);
}
```
