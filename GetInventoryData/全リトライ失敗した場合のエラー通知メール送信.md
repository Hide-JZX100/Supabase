# 開発指示書：Webhook送信失敗時のメール通知機能実装

**プロジェクト名：** NE_在庫情報取得（GetInventoryData）
**対象Issue：** Webhook呼び出し全リトライ失敗時のエラー通知メール送信
**前提：** Phase B（送信側の直接呼び出し方式）が実装済みであること
**目的：** `callDistributeInventory()` がリトライを含め完全に失敗した場合に、実行ログだけでなくメールでも即座に検知できるようにする

---

## 1. 背景

送信側（GetInventoryData）から受信側（DistributeInventory）へのWebhook呼び出しが
全リトライ（3回）失敗した場合、現状は `logError()` による実行ログへの記録のみで、
外部への通知は一切行われない。

固定時刻トリガー（フェイルセーフ）が後続で配布処理を救済してくれる設計のため、
実害が出にくい反面、この救済によって障害の発生自体が静かに隠れてしまう。
2026/07/13にOAuth同意画面がテストモードであったことに起因する403エラーが
複数回発生していたが、実行ログを直接確認するまで誰も気づけない状態だった。

---

## 2. 方針（確定事項）

- メール送信処理は **DistributeInventory側の `sendErrorMail()` と同じ設計思想**で、
  GetInventoryData側にも汎用関数として新設する（案B採用）
- 通知先メールアドレスは、スクリプトプロパティで管理せず、
  **`Session.getEffectiveUser().getEmail()` でスクリプト所有者のGmailアドレスを動的に取得する**
  - 理由：本プロジェクトの学びにある通り、時間主導型トリガー実行中は
    `Session.getActiveUser()` が空文字を返すため、`getEffectiveUser()` を用いる必要がある
  - 通知先を固定のGmailアドレスにするため、`ERROR_NOTIFICATION_EMAIL` のような
    スクリプトプロパティは新設しない
- メール送信自体の例外は必ずtry-catchで保護し、無限ループや二次エラーを起こさない

### タスク1：`12_Logger.ログ管理.gs` に `sendErrorMail()` を追記

ファイル末尾（既存の `showRetryStats()` 関数の直後）に以下を追記する。

#### 関数仕様

**`sendErrorMail(subject, body)`**

- スクリプト所有者（`Session.getEffectiveUser().getEmail()`）宛にメールを送信する
- 送信処理自体で例外が発生した場合は、`console.error()` のみで記録し、
  呼び出し元には例外を伝播させない（無限ループ防止のため、`logError()` は使わずconsole.errorに留める）
- DistributeInventory側の `sendErrorMail()`（12_Logger.ログ管理.gs）と対になる設計とする

#### 実装イメージ

```javascript
// ============================================================================
// メール通知送信
// ============================================================================

/**
 * スクリプト所有者宛にエラー通知メールを送信する
 *
 * 通知先はスクリプトプロパティではなく、Session.getEffectiveUser().getEmail() で
 * 動的に取得したスクリプト所有者のGmailアドレスとする。
 * 時間主導型トリガー実行中は Session.getActiveUser() が空文字を返すため、
 * 必ず getEffectiveUser() を使用すること。
 * 送信処理自体でエラーが発生した場合は、コンソールにエラーを出力するのみとし、
 * 呼び出し元には例外を伝播させない（無限ループ防止）。
 *
 * @param {string} subject - メールの件名
 * @param {string} body    - メールの本文
 * @return {void}
 */
function sendErrorMail(subject, body) {
    try {
        const recipient = Session.getEffectiveUser().getEmail();

        if (!recipient) {
            console.error('通知先メールアドレスが取得できなかったため、メール送信をスキップします。');
            return;
        }

        MailApp.sendEmail({
            to: recipient,
            subject: subject,
            body: body
        });

        console.log('エラー通知メールを送信しました: ' + recipient);

    } catch (error) {
        // メール送信時のエラーは無限ループを防ぐため、console.error のみで出力する
        console.error('エラー通知メール送信中に例外が発生しました:', error.message);
    }
}
```

#### `testCallDistributeInventoryFailureNotification()`

**目的：** `RECEIVER_WEBAPP_URL` を一時的に不正な値に差し替え、
実際に `callDistributeInventory()` を実行してリトライが全滅し、
メール通知まで一気通貫で動作するか確認する。

**注意：** このテストはリトライ3回（最大約1〜数秒 + バックオフ待機）を実際に消費するため、
実行に時間がかかる。また終了後に必ずプロパティを元に戻すこと。

```javascript
/**
 * callDistributeInventory() のリトライ全滅シナリオ確認テスト
 *
 * RECEIVER_WEBAPP_URL を一時的に無効なURLへ差し替えた上で
 * callDistributeInventory() を実行し、リトライが全滅した際に
 * メール通知まで正しく動作するかを確認する。
 * 元のプロパティ値を破壊しないよう、一時退避と復元を行う。
 */
function testCallDistributeInventoryFailureNotification() {
    console.log('=== callDistributeInventory リトライ全滅シナリオテスト ===\n');

    const properties = PropertiesService.getScriptProperties();
    const originalUrl = properties.getProperty('RECEIVER_WEBAPP_URL');

    try {
        // 実在しないURLに差し替えて強制的に失敗させる
        properties.setProperty('RECEIVER_WEBAPP_URL', 'https://script.google.com/macros/s/invalid_dummy_id/exec');

        console.log('RECEIVER_WEBAPP_URL を一時的に無効な値へ差し替えました。');
        console.log('callDistributeInventory() を実行します（リトライで数秒〜十数秒かかります）...\n');

        callDistributeInventory();

        console.log('\n✓ callDistributeInventory() の実行が完了しました。');
        console.log('  受信トレイにエラー通知メールが届いているか確認してください。');

    } catch (error) {
        console.error('❌ 予期しない例外が発生しました: ' + error.message);
    } finally {
        // 元のURLを必ず復元する
        if (originalUrl !== null) {
            properties.setProperty('RECEIVER_WEBAPP_URL', originalUrl);
            console.log('\nRECEIVER_WEBAPP_URL を元の値に復元しました。');
        } else {
            properties.deleteProperty('RECEIVER_WEBAPP_URL');
            console.log('\n元々未設定だったため、プロパティを削除しました。');
        }
    }

    console.log('\n=== テスト完了 ===');
}
```
